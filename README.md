# DIO Agent na Prática

Desafio de Projeto da [DIO](https://dio.me): configure o [DIO Agent](https://github.com/digitalinnovationone/dio-agent) e use as skills dele para estudar, praticar e planejar a sua carreira.

**Como entregar:** clique em **Use this template** para criar a sua cópia, siga os 4 passos, preencha os ✏️ e entregue o link do seu repositório na DIO.

---

## 1. Configure o DIO Agent

1. Instale um harness. Recomendamos o [Google Antigravity](https://antigravity.google/docs), mas qualquer um [da lista do DIO Agent](https://github.com/digitalinnovationone/dio-agent#-comece-em-3-passos) funciona.
2. Baixe o [DIO Agent](https://github.com/digitalinnovationone/dio-agent): botão **Code**, depois **Download ZIP**, e extraia. Se você usa Git, pode clonar.
3. No harness, abra a pasta que tem o arquivo `AGENTS.md`. Pelo .zip, ela se chama `dio-agent-main`.
4. Mande o primeiro prompt:

```
Oi!
Quem é você e como pode me ajudar nos meus estudos na DIO?
```

Se ele se apresentar como DIO Agent, deu certo. Se responder como um assistente qualquer, confira a pasta aberta.

✏️ **Meu harness:** qual escolhi e por quê.

✏️ **Print:** envie a imagem em **Add file**, **Upload files**, com o nome `print-do-agente.png`, e cole aqui a linha `![DIO Agent respondendo](print-do-agente.png)`.

## 2. Estudar

Peça para o agente explicar um conceito. Troque pelo que você quer entender:

```
Me explica o que é uma skill de um agente de IA.
Meu nível: já uso IA no dia a dia, mas nunca configurei um agente.
```

✏️ **O que aprendi:** o conceito e a explicação, com as suas palavras.

## 3. Praticar

Use um desafio em que você travou ou este exemplo. O agente dá dicas, não a resposta pronta:

```
Estou travado em um Desafio de Código da DIO.
O que o desafio pede: ler um número inteiro N e imprimir a soma de todos os números de 1 até N.
Onde eu travei: meu código imprime só o último número, não a soma.
Meu código:
let n = parseInt(gets());
let soma = 0;
for (let i = 1; i <= n; i++) {
  soma = i;
}
print(soma);
Me ajuda a destravar sem dar a resposta pronta.
```

✏️ **Como destravei:** a dica que ajudou e o que você mudou.

## 4. Planejar

Cole o link da Trilha que você está fazendo na DIO, seja um Bootcamp ou uma Formação:

```
Quero montar um plano de estudos.
Meu objetivo: concluir esta Trilha em [4 semanas].
O que quero fazer na DIO: [link da Trilha]
Meu nível hoje: [iniciante, intermediário ou avançado]
Tempo disponível: [ex: 1 hora por dia, de segunda a sexta]
```

✏️ **Meu plano de estudos:** cole o plano e ajuste à sua rotina.

## Bônus: seu próximo passo

Quer construir com IA? O agente ajuda a escolher a Formação da Carreira AI Builder que combina com você:

```
Quero escolher meu próximo passo na Carreira AI Builder.
O que quero construir com IA: [ex: um app para organizar os pedidos do meu negócio]
Minha experiência com programação: [nenhuma, o básico, trabalho com desenvolvimento]
Meu objetivo: [ex: tirar uma ideia do papel]
```

✏️ **Meu próximo passo:** o que você vai estudar ou construir depois deste Desafio.
